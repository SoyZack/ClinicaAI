# 🏥 CliniAI

Sistema de gestión clínica y triaje automatizado desarrollado con ASP.NET Core MVC.

## 🚀 Características principales
* **Gestión de Citas:** Control y programación de citas médicas con validación de disponibilidad.
* **Módulo de Consultas:** Registro y seguimiento de historiales de pacientes.
* **Asistente de Triaje (IA / Mock):** Sistema de asistencia preliminar para clasificar síntomas y prioridades de los pacientes de forma rápida y segura.

## 🛠️ Tecnologías utilizadas
* **Backend:** C#, ASP.NET Core MVC, Entity Framework Core.
* **Frontend:** Razor Views, Bootstrap, JavaScript.
* **Base de datos:** SQL Server / MySQL.
